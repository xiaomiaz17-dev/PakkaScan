PakkaScan closed-beta MVP
=======================
Need: Node.js 20+ from https://nodejs.org

1. Unzip PakkaScan-App-MVP.zip into a folder
2. Open terminal in that folder
3. npm install
4. npm run dev
5. On the SAME PC open: http://localhost:3000/app/scan

Paste document text, choose jurisdiction, Analyse.
localhost will not work on your phone.
Marketing site: https://pakkascan.com
